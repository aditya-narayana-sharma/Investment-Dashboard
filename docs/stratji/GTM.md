# Stratji Go-To-Market

**Status:** TARGET. No public paid launch until P7.

## 1. Narrative

Stratji is the on-device operating system for an Indian-market book: live broker state, sector analytics, Mail/Podcast intelligence, private Health, and white-box strategies — with Streak as the only live algo venue.

Contrast: not a hosted robosignal, not an RA newsletter, not a Composer clone that copies US books.

## 2. Channel

1. stratji.co.in marketing + docs
2. GitHub source-available repo
3. Closed Mac beta (10 users) before public GitHub
4. Demo video from **sample data only** (`npm run demo:record`)
