## Findings

### [P1] Documents-Allow persistence migration is inert under `app-sandbox = false`

- **Status:** Probable (entitlements-inert = Confirmed; exact bookmark runtime = Probable, app not launched this pass)
- **Confidence:** High
- **Affected:** Stratji.app (native shell) → repo-root resolution / Documents I/O → all workspaces via shared launch path
- **Symptom:** RCA-2026-08-24 root cause #5 ("App Sandbox is false, so `files.bookmarks.app-scope` does not persist Allow") was the fault the remediation set out to close; the commit adds the entitlements and security-scoped-bookmark code but leaves `app-sandbox = false`.
- **Reproduction:** static — `apple-app/Stratji/Stratji.entitlements:37` is `com.apple.security.app-sandbox <false/>`; lines 46–48 add `files.user-selected.read-write` and `files.bookmarks.app-scope` (both sandbox-only); `apple-app/Stratji/StratjiConfiguration.swift:258–260` resolves the bookmark with `options: [.withSecurityScope, .withoutUI]` and `:168` calls `startAccessingSecurityScopedResource()`.
- **Observation/evidence:** `.withSecurityScope` bookmark creation is unsupported for a non-sandboxed process; `persistBookmark` cannot store usable data, so `resolveBookmarkedRepoRootLocked()` returns nil on the next launch and the code degrades to the plain-path/FDA fallback. The two entitlements have no runtime effect while the sandbox is off.
- **Proximate mechanism:** the entitlements and `.withSecurityScope` API are gated on the App Sandbox, which is disabled.
- **Root cause:** the migration changed the *manifest and helper code* but not the *sandbox state* the original root cause was about — a half-migration.
- **Trigger:** operator Allows Documents / picks the folder once, expecting `?view=` changes to stop re-prompting.
- **Contributing factors:** the entitlements file's own comment (`:13–15`) asserts the bookmark "persists the git checkout," reinforcing a guarantee the build disables.
- **User impact:** low-to-moderate today — persistence still works via FDA where FDA is granted; the risk is latent (see residual risk) and the stated fix is not the actual fix.
- **Corrective action:** choose one and make manifest + code agree — (a) enable `app-sandbox` and complete the entitlement/FDA audit so the bookmark truly persists Allow, or (b) drop the two sandbox-only keys and `.withSecurityScope`, and document FDA as the persistence mechanism.
- **Verification:** after the choice, launch Stratji.app, Allow once, switch `?view=` across all six workspaces and return focus → zero re-prompt; confirm via `~/Library/Logs/PortfolioIntelligence` breadcrumbs that no Documents `stat` occurs on navigate (already asserted green by `tests/stratji-documents-tcc.test.mjs`).
- **Code:** `apple-app/Stratji/Stratji.entitlements:37`, `:46`; `apple-app/Stratji/StratjiConfiguration.swift:258`, `:168`
- **Source:** Apple App Sandbox / security-scoped bookmark contract; prior `RCAs/2026-08-24-localhost-vs-stratji.md` root cause #5
